# Love Map

React + Vite로 만든 두 사람의 애정 지도입니다. 실제 모드는 Google Sheets + Apps Script에 연결하며, 미리보기는 별도 브라우저 저장소에서 동작합니다.

## 실행

`npm install`, `npm run dev`로 개발 화면을 엽니다. `npm test`로 기능을 검사하고 `npm run build`로 배포 파일을 만듭니다. 서버 배포 파일은 `npm run build:server`로 생성합니다.

## 실제 연결

최신 설치 대상은 **[apps-script/production/Code.gs](apps-script/production/Code.gs) 하나**입니다. [설치 안내](apps-script/production/README.md)에 따라 Google에서 배포하고, GitHub Actions 변수 `VITE_APPS_SCRIPT_URL`에 배포 주소를 넣습니다. [전체 배포 순서](DEPLOYMENT.md)를 참고하세요.

배포된 Apps Script 주소를 앱의 기본 연결 주소로 설정했습니다. GitHub Actions 변수를 따로 넣지 않아도 기본 주소를 사용하며, VITE_APPS_SCRIPT_URL로 변경할 수 있습니다. 실제 서버의 정상 응답·비로그인 접근 차단·브라우저 교차 출처 응답을 확인했습니다. 회원 가입 이후의 두 기기 실사용 검증은 남아 있습니다. 개발 서버도 실제 저장소를 사용하며, 로그인 없이 들어가는 미리보기는 계속 별도 저장소를 사용합니다.

## 두 사람의 시작

1. 첫 사람이 이름, 개인 PIN, 연결 코드, 사귀기 시작한 날을 정하고 개인 복구 코드를 보관합니다.
2. 상대방은 자신의 이름·개인 PIN과 공유받은 연결 코드로 같은 공간에 연결합니다.
3. 다음 방문에는 기기에 기억된 본인 계정의 PIN으로 입장합니다.
4. 새 기기에서는 본인 복구 코드로 연결합니다. 사용 후 새 복구 코드가 발급되며 본인의 기존 세션은 만료됩니다.
5. 계정 설정에서 개인 PIN 변경, 복구 코드 재발급, 로그아웃을 합니다. 연결 전에는 연결 코드 재발급도 가능합니다.

같은 커플의 두 개인 PIN과 연결 코드는 달라야 합니다. 연결 코드는 하루 후 또는 두 사람 연결 완료 시 만료되며, 개인 계정에 입장하는 용도로 사용할 수 없습니다. PIN 5회 오류는 해당 계정의 5분 대기, 세션 유효기간은 12시간입니다.

## 최신 화면과 저장

- 알아가기: 현재 사용하는 카테고리·아코디언 화면과 두 사람의 답변·수정 소식·읽음 상태를 저장합니다. 현재 화면에는 공개 범위 선택 기능이 없으며 답변은 커플 안에서 공유합니다. 과거 질문 작성 화면은 제거했습니다.
- 점검하기: 월별 최신 결과와 O/X 답변을 저장합니다.
- 질문하기: 27문제의 커플 공통 추첨 순서, 직접 만든 질문, 두 사람의 답변을 저장합니다.
- 오늘의 질문: 상대방의 이번 달 최신 점검 결과에서 X인 항목만 사용하며, 완료한 항목은 새 결과가 나오기 전까지 다시 묻지 않습니다.
- 게임: 애정 지도 게임 진행·완료 기록, 택택토·오목·펀치기계의 차례와 결과를 저장합니다.
- love box: 로그인한 사람의 새롭게 알게 된 점과 질문하기에서 저장한 두 사람의 답변을 분류·월별로 보여줍니다.
- 모든 비교에서 본인 기록이 왼쪽, 그래프 본인 기록은 실선입니다.
- 미리보기는 여보·자기와 1일째를 표시하며 실제 계정·기록을 읽거나 전송하지 않습니다.

PIN 검증과 커플 접근 권한은 서버에서 처리합니다. 개인 세션 토큰은 탭의 sessionStorage에, 기기에서 기억할 회원 ID·표시 이름만 localStorage에 저장합니다. 이전 로컬 테스트 계정이나 미리보기 기록을 실제 시트로 가져오지 않습니다.

상위 apps-script 폴더의 Google 로그인 코드는 과거 초안이며 최신 서버에 포함하지 않습니다. 앱에는 Supabase 호출이나 의존성이 없습니다.
